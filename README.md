## Research experience

**MSc thesis — Planning targeted proteomics experiments (PRM) in R**

Designed a computational workflow for selecting peptide precursors for parallel reaction monitoring (PRM) based on proteomics identification evidence, sequence constraints, precursor properties and chromatographic retention times. The research involved DIA-NN outputs, LC-MS/MS concepts, peptide filtering, iRT calibration and analysis of acquisition-window crowding.

Selected results and the pipeline structure are described in the [PRM research case study](projects/prm-proteomics.md). Source code and selected output summaries have been packaged for a separate, curated public release; the code is not yet hosted in a dedicated public GitHub repository.

**BSc thesis — Molecular simulations of n-octane, n-dodecane and n-pentadecane**

Used GROMACS simulations to investigate thermodynamic and kinetic properties and compare force-field behavior against reference data. [Explore the project](https://github.com/Daniello333/BSc-Daniel-Drabik-2024).
